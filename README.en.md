# CUMT Alethic Insight Lab Public Governance

This repository contains public governance documents for CUMT Alethic Insight Lab.

It is intended for members, applicants, collaborators, and future student maintainers who need a clear view of how the community works.

Boundary: this repository only holds public-facing governance documents; internal processes live in the private `internal-governance` repository, and infrastructure handoff lives in the private `infra-handoff` repository.

## Documents

| Document | Description |
| --- | --- |
| [Charter](docs/en/charter.md) | What the lab is: mission, scope, and operating principles. |
| [Membership](docs/en/membership.md) | Member types, expectations, and access rules. |
| [Project Governance](docs/en/project-governance.md) | How projects start, repository rules, and maintainer duties. |
| [Open-Source Policy](docs/en/open-source-policy.md) | Issue-first workflow and practices to avoid. |
| [AI Assistance Policy](docs/en/ai-assistance-policy.md) | Disclosure, verification, and testing requirements for AI-assisted work. |
| [Release Policy](docs/en/release-policy.md) | Semantic versioning and release-note requirements. |
| [Review Policy](docs/en/review-policy.md) | What reviewers check and what contributors should do. |

## Repository Defaults

| Item | Default |
| --- | --- |
| Code license | MIT (see the LICENSE in project-template) |
| Content license | CC-BY-4.0 for docs/tutorials; CC0 for curated lists |
| CI/CD | Not required. Practice, competition, and course projects ship without CI; content repositories (e.g. awesome-ai) may run non-blocking scheduled maintenance such as weekly link checks. |

## Sensitive Materials

This public repository must not contain real recruitment questions, interview records, scoring rubrics, candidate evaluations, credentials, tokens, recovery codes, private datasets, unreleased checkpoints, or internal incident records.

Sensitive governance and handoff materials belong in private repositories with limited access.
