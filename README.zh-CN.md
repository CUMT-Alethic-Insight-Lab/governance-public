# CUMT Alethic Insight Lab 公开治理文档

本仓库用于存放 CUMT Alethic Insight Lab 的公开治理文档。

它面向成员、申请者、合作者和未来学生维护者，目标是清楚说明这个共同体如何运作。

边界：本仓只管面向公众的治理文档；内部流程归 `internal-governance`（私有）、基础设施归 `infra-handoff`（私有）。

## 文档

| 文档 | 说明 |
| --- | --- |
| [章程](docs/zh-CN/charter.md) | 实验室的定位、使命、方向与基本原则。 |
| [成员规则](docs/zh-CN/membership.md) | 成员类型、行为期望与访问权限。 |
| [项目治理](docs/zh-CN/project-governance.md) | 如何立项、仓库规则与维护者职责。 |
| [开源政策](docs/zh-CN/open-source-policy.md) | Issue 优先的协作流程与应避免的做法。 |
| [AI 辅助使用规则](docs/zh-CN/ai-assistance-policy.md) | AI 辅助贡献的披露、核验与测试要求。 |
| [发布规范](docs/zh-CN/release-policy.md) | 语义化版本与发布说明要求。 |
| [Review 规则](docs/zh-CN/review-policy.md) | Review 者的检查项与贡献者的配合事项。 |

## 敏感材料

本公开仓库不得包含真实招新题、面试记录、评分标准、候选人评价、凭证、token、恢复码、私有数据集、未公开模型权重或内部事故记录。

敏感治理和交接材料应放在访问受限的私有仓库中。
